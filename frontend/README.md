# 🌸 Saheli Connect (Frontend)

This directory contains the React + Vite frontend for **Saheli Connect**, a Social Support Coordination Platform.

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge&logo=vercel)](https://saheli-connect.vercel.app/)

## 🚀 Live Demo
Check out the platform live here: **[saheli-connect.vercel.app](https://saheli-connect.vercel.app/)**

## Setup Instructions
To run this frontend locally over the backend:

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

For the full project documentation, including the FastAPI backend setup, please see the [root README.md](../README.md).
